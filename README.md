# 🎙️ Изменение Голоса | Voice Changer — Landing Page

Официальный статический лендинг сервиса изменения голоса в Telegram (**[@VoicePresetBot](https://t.me/VoicePresetBot?start=landing)**).

---

## ✨ Особенности лендинга:
- 🎨 **Киберпанк / Неон Glassmorphism** дизайн в цветовой палитре официального логотипа (**Electric Cyan** + **Radiant Magenta/Purple**).
- 🎧 **Интерактивный Web Audio API синтезатор**: возможность прослушать живую симуляцию звучания всех 18 голосов прямо в браузере.
- 📊 **FFT Waveform Canvas**: динамическая визуализация частотного спектра речи в реальном времени.
- ⚖️ **Раздел правовой безопасности (`#safety`)**: разъяснение законности использования, таблица рисков и запрет на противоправное применение (ст. 159 УК РФ).
- 🔍 **SEO & GEO оптимизация**: органичные ключевые слова, разметка **Schema.org** (`SoftwareApplication`, `FAQPage`, `Offer`).
- 📱 **100% адаптивность**: слайд-меню (бургер-дровер) для смартфонов и планшетов, плавающая кнопка быстрого запуска.
- 🎯 **Целевое действие**: запуск бота с UTM-меткой `https://t.me/VoicePresetBot?start=landing`.

## 🚀 Запуск и деплой:
Лендинг полностью статичен (чистый HTML5, CSS3, Vanilla JavaScript) и готов к деплою на **GitHub Pages**, **Vercel**, **Netlify**, **Cloudflare Pages** или любой Nginx / Caddy веб-сервер.

### Локальный запуск:
```powershell
python -m http.server 8089
```
Открыть в браузере: **http://localhost:8089/**
